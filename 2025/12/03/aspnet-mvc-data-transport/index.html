ASP.NET MVC 資料傳值方式整理（ViewBag / ViewData / TempData / Model）

發表於 2025-12-03 分類於 後端
簡易介紹MVC如何傳遞資料

目錄

  • 1. Model（最推薦）
  • 2. ViewBag
  • 3. ViewData
  • 4. TempData
  • 資料傳值方式比較表

1. Model（最推薦）

用途：
傳遞主要、結構化的強型別資料至 View。

特點：

  • 強型別（編譯期檢查）
  • 適合複雜資料
  • 最標準、安全的傳值方式

範例 :

// 1. Model 定義 (在 Models 資料夾)
public class Student
{
    public int ID { get; set; }
    public string Name { get; set; }
}

// 2. Controller
public ActionResult Details()
{
    var student = new Student { ID = 101, Name = "Leo Wang" };
    return View(student); // 將強型別 Model 傳遞給 View
}

// 3. View (Details.cshtml)
@model YourNamespace.Models.Student // 宣告 Model 型別

<h2>學生編號: @Model.ID</h2>
<p>學生姓名: @Model.Name</p>

2. ViewBag

用途：
傳遞短暫、輕量的資料至 View。

特點：

  • 動態型別（易拼字錯誤）
  • 僅於目前 Request 存活
  • 使用最方便

3. ViewData

用途：
與 ViewBag 相同，用於傳遞輕量資料。

特點：

  • 字典型別（key-value）
  • 僅於目前 Request 存活
  • 舊版 MVC 常使用

範例 :

// 1. Controller
public ActionResult Index()
{
    // ViewData (使用字串鍵值存取，需手動轉型)
    ViewData["Title"] = "首頁資料列表";
    ViewData["UserCount"] = 50;

    // ViewBag (動態屬性存取，不需轉型)
    ViewBag.IsAdmin = true;
    ViewBag.WelcomeMessage = "歡迎回來！";

    return View();
}

// 2. View (Index.cshtml)
@{
    ViewBag.Title = ViewData["Title"]; // 也可以互相操作
}

<h3>@(string)ViewData["Title"]</h3>
<p>線上人數: @ViewData["UserCount"]</p>

@if (ViewBag.IsAdmin)
{
    <p>@ViewBag.WelcomeMessage (管理員)</p>
}

4. TempData

用途：
可跨 Request 傳值（通常用於 Redirect 情境）

例如：Post → Redirect → View

特點：

  • 使用 Session 暫存
  • 一次性資料（讀取後會移除）
  • 適合用於成功/錯誤提示訊息

範例 :

// 1. Controller A: 處理表單提交並重新導向
[HttpPost]
public ActionResult Create(SomeModel model)
{
    // ... 執行資料庫儲存操作 ...

    // 將成功訊息存入 TempData
    TempData["StatusMessage"] = $"資料 {model.Name} 已成功儲存！";

    // 重新導向到列表頁
    return RedirectToAction("List");
}

// 2. Controller B: 列表頁
public ActionResult List()
{
    // 讀取 TempData。讀取後，該資料會自動從 Session 中移除。
    if (TempData.ContainsKey("StatusMessage"))
    {
        ViewBag.Message = TempData["StatusMessage"];
    }

    return View();
}

// 📌 保持資料的方法 (選用)
// 如果想在讀取後不清除 TempData，可以使用 TempData.Keep("Key") 或 TempData.Peek("Key")
// TempData.Keep("StatusMessage");

資料傳值方式比較表

傳值方式 型別 型別安全 生命週期 適用場景
Model 強型別 (class) 高 (編譯時期檢查) 單一請求 (Controller -> View) 頁面所需的主要資料物件或複雜結構。最推薦。
ViewData 弱型別 (Dictionary<string, object>) 低 (執行時期轉型) 單一請求 (Controller -> View) 輔助性資料、少量訊息、下拉式選單選項。
ViewBag 弱型別 (dynamic) 低 (執行時期錯誤) 單一請求 (Controller -> View) 與 ViewData 相似，寫法較簡潔。
TempData 弱型別 (Dictionary<string, object>) 低 (執行時期轉型) 跨越一次 HTTP 請求 RedirectToAction 後的訊息傳遞（如：操作成功通知）。
